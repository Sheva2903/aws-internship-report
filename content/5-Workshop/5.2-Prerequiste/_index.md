- An AWS account with permission to create resources in: VPC, EC2, RDS, S3, IAM (Free Tier is sufficient - every step in this lab stays within free-tier limits when using the recommended instance/storage types)
- Every resource (VPC, EC2, RDS, S3) is created in the same region (e.g., `ap-southeast-2 (Singapore)`)
- Tools: just a web browser for the AWS Console - every step is done manually through the web UI to keep the focus on understanding each configuration
- An SSH client to connect to EC2 once created (e.g., MobaXterm, or the built-in ssh on Mac/Linux/Git Bash)
- Helpful background: basic familiarity with VPC/Subnet/Security Group concepts, and having run PostgreSQL or a Spring Boot app locally before (not required, but makes the lab easier to follow)
